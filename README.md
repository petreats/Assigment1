# Sensor Analysis Tool
With this program you are able to:
    Choose between 5 different sensors 
    Generate random readings within a set maximum and minimum limit
    Set a threshold and see which readings are above and below it
    Calculate statistics  
    Save readings to CSV file and load them as well
    Visualise data on line plot or histogram

Use commands (1-5) to choose programs or q to quit

In the terminal use the following to install the required packages:
pip install -r requirements.txt
